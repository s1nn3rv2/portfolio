# Personal Portfolio

This is my portfolio site, it's viewable on [s1nn3rv2.github.io/portfolio](https://s1nn3rv2.github.io/portfolio).

## Tech Stack

* **Framework**: Astro
* **Styling**: Tailwind CSS 4
* **Scripting**: TypeScript

## Local Setup

All commands are run from the root of the project. Ensure you have `pnpm` installed:

### 1. Install Dependencies
```sh
pnpm install
```

### 2. Run Local Development Server
```sh
pnpm dev
```
*Starts the development server at `localhost:4321`.*

### 3. Build for Production
```sh
pnpm build
```

### 4. Preview Production Build Locally
```sh
pnpm preview
```
